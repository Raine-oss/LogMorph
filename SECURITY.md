# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 0.1.x | Yes |
| < 0.1.0 | No |

---

## Reporting a Vulnerability

Because LogMorph uses native code via JNI and parses untrusted input from external log files, we take security reports seriously.

If you discover a security vulnerability, memory safety issue, or buffer overflow risk, please do not open a public issue. Instead, report it privately via email:

- **Email**: [rainebriars@gmail.com](mailto:rainebriars@gmail.com)
- **Subject**: `[SECURITY] Vulnerability Report for LogMorph`

Please include:
1. A clear description of the issue.
2. Steps to reproduce or a sample malformed log file.
3. Impact assessment.

We will acknowledge receipt within 48 hours and work with you on a resolution before making any public disclosure.
